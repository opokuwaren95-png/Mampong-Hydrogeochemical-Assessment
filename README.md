I have a background in Chemistry Education and I am currently studying Computer Science as well. I am interested in moving into computational chemistry and cheminformatics, so I have started learning Python and some of the tools used for scientific and chemical data analysis.

This repository is part of that learning journey.

### Thesis Context
This repository is an independent computational extension of data collected for my BSc Final Year Thesis: "Hydrogeochemical Assessment of Groundwater in Asante Mampong, Ghana" (USTED, August 2026). Thesis = experimental field & lab work. This repo = independent Python analysis for graduate studies.

### About This Project
This project is based on my final-year research on the hydrogeochemical assessment of groundwater in Asante Mampong. The dataset contains results from 11 groundwater samples.

Some of the things I have worked on include:
* Calculating basic statistics such as mean, minimum and maximum
* Looking at pH, EC, TDS and turbidity
* Creating bar charts
* Creating a histogram for TDS
* Creating a scatter plot for TDS and EC
* Comparing results with water-quality guidelines

 ### Tools I Used
* Python, Jupyter Notebook, Pandas, NumPy, Matplotlib
* Currently continuing with SciPy, next RDKit, followed later by  PySCF / Psi4

### Why I Created This Repository
I wanted to use my own chemistry research data while learning Python instead of only following programming tutorials. It is the beginning of my transition from chemistry education towards computational chemistry.
