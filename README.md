### Thesis Context

This repository is an independent computational extension of data collected for my BSc Final Year Thesis: "Hydrogeochemical Assessment of Groundwater in Asante Mampong, Ghana" (USTED, August 2026). 

Thesis = experimental field & lab work. This repo = independent Python analysis for graduate studies in Computational Chemistry.

### About This Project

This project is based on my final-year research on the hydrogeochemical assessment of groundwater in Asante Mampong.

The dataset contains results from **11 groundwater samples (GW01 - GW11)**. I used Python to organize the data, perform basic analysis, and create plots to better understand the results.

Some of the things I have worked on include:

* Calculating basic statistics such as mean, minimum and maximum
* Looking at pH, EC, TDS and turbidity
* Creating bar charts for all 11 samples
* Creating a histogram for TDS
* Creating a scatter plot for TDS and EC correlation
* Comparing results with WHO water-quality guidelines
